Support

Help with PlainLaunch, the plain text widget.

Add the widget

  1. Touch and hold an empty area of your Home Screen until the icons jiggle.
  2. Tap the + button.
  3. Search for "PlainLaunch".
  4. Choose the Large size, then tap "Add Widget".
  5. Tap Done.

Some names need a Shortcut first

iOS does not let any app open Camera, Settings, or a third-party app like Anker soundcore directly. For those, PlainLaunch asks the Shortcuts app to run a shortcut you create once. Open PlainLaunch → Test tab to see exactly which entries need this, then:

Shortcuts → + → Add Action → "Open App" → choose the target app → name it exactly as shown in the Test tab (e.g. "Open Camera") Repeat for each entry marked "Needs Shortcut".

Something isn't opening

  • Open PlainLaunch and go to the Test tab — tap the name to see the exact result.
  • If it needs a Shortcut, confirm the shortcut's name matches exactly (including capitalization).
  • For Music/Podcasts, make sure Apple Music / Apple Podcasts is installed.
  • For Soundcore, make sure the Anker soundcore app is installed.

サポート

シンプルなテキストWidget「PlainLaunch」のヘルプ。

Widgetを追加する

  1. ホーム画面の何もない場所を長押しし、アイコンが揺れる状態にします。
  2. ＋ボタンをタップします。
  3. 「PlainLaunch」を検索します。
  4. サイズを「Large」に選び、「Widgetを追加」をタップします。
  5. 「完了」をタップします。

一部の項目には事前にShortcutの作成が必要です

iOSの仕組み上、どのアプリもCameraやSettings、Anker soundcoreのような他社アプリを直接開くことはできません。これらについてはPlainLaunchからShortcutsアプリに依頼し、あらかじめ作成しておいたショートカットを実行します。PlainLaunchの「起動テスト」タブで、どの項目が対象かを確認できます。

ショートカット → ＋ → アクションを追加 → 「Appを開く」 → 対象のアプリを選択 → 「起動テスト」タブに表示されている名前と完全に一致する名前を付ける（例:「Open Camera」） 「要Shortcut」と表示されている項目それぞれについて繰り返してください。

起動しない場合

  • PlainLaunchを開き、「起動テスト」タブで名前をタップして結果を確認してください。
  • Shortcutが必要な項目は、ショートカットの名前が（大文字・小文字も含めて）完全に一致しているか確認してください。
  • Music / Podcastsの場合は、Apple MusicまたはApple Podcastsアプリがインストールされているか確認してください。
  • Soundcoreの場合は、Anker soundcoreアプリがインストールされているか確認してください。
